# Task 2: Exploratory Data Analysis (EDA)

## Objective 

The objective of this project was to analyze the dataset and identify patterns, trends, distributions, and outliers using Exploratory Data Analysis (EDA).

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Analysis Performed

### Data Exploration

* Examined dataset structure and column information.
* Checked data types and dataset dimensions.

### Missing Value Analysis

* Identified missing values in the dataset.
* Evaluated data quality before analysis.

### Descriptive Statistics

* Calculated count, mean, median, minimum, maximum, and standard deviation.
* Analyzed key numerical features.

### Distribution Analysis

* Visualized data distributions using histograms.
* Studied the spread of transaction values.

### Outlier Detection

* Used boxplots to identify unusual observations.
* Detected high-value transaction outliers.

### Product Analysis

* Analyzed product-wise order frequency.
* Identified the most frequently purchased products.

### Trend Analysis

* Examined sales trends over time.
* Identified patterns in customer purchasing behavior.

## Key Findings

* The dataset showed a right-skewed distribution of transaction values.
* Several high-value outliers were identified.
* Product demand varied significantly across categories.
* Sales trends indicated changes in customer purchasing behavior over time.
* The analysis revealed useful business insights for decision-making.

## Skills Demonstrated

* Data Analysis
* Descriptive Statistics
* Data Visualization
* Trend Analysis
* Outlier Detection
* Business Insight Generation

## Conclusion

The Exploratory Data Analysis successfully uncovered trends, distributions, and outliers within the dataset. These insights can help support data-driven decision-making and provide a strong foundation for further analytics and machine learning projects.
